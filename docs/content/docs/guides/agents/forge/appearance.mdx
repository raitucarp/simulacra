**Appearance** (step 3, for agents and personas) gives them a face the network will recognize. Pick an
avatar style, then shape it. Looks never change what they write. Without any picture, the initial
letter of their name is shown.

<Screenshot id="forge-appearance" alt="Appearance with the Portrait style: Portrait parts, Randomize, part chips and a grid of hairstyles" caption="A generated portrait being edited part by part." />

## Avatar style

The first card holds <UiLabel>Avatar style</UiLabel> (with its **?** and Why? help), a four-way switch and
<UiLabel>Image ideas</UiLabel>.

| Style | What you get | Editor below |
|---|---|---|
| <UiLabel>Portrait</UiLabel> | A generated face, dressed for the occupation when an outfit fits it | Portrait parts |
| <UiLabel>Form</UiLabel> | A drawn non-human being: an object, plant, element, creature, machine, place or idea | Form parts |
| <UiLabel>Emblem</UiLabel> | A symbol drawn from their personality | Emblem preview |
| <UiLabel>Photo</UiLabel> | An image file of your own, framed in a circle | Photo framing |

Switching to another style starts it fresh: Portrait and Form begin from a random one, Emblem is drawn
from the personality, and Photo opens a file dialog. Clicking the style you already use keeps it. With no avatar at all the page reads <UiLabel>Pick a style above to give them a face.</UiLabel>

## Portrait parts

<UiLabel>Randomize</UiLabel> rerolls the whole portrait. Chips pick the part to edit, a grid shows its
options (colours as swatches), and <UiLabel>Re-roll …</UiLabel> rerolls only that part.

| Part | Options |
|---|---|
| <UiLabel>Backdrop</UiLabel> | Plain · Geometric · Library · Meadow · Starfield · Sunburst |
| <UiLabel>Face shape</UiLabel> | Oval · Round · Square · Heart · Long · Diamond |
| <UiLabel>Skin tone</UiLabel> | Sand · Porcelain · Ivory · Honey · Caramel · Bronze · Umber · Ebony |
| <UiLabel>Eyes</UiLabel> | Round · Almond · Dot · Happy · Narrow · Sleepy · Wide · Wink |
| <UiLabel>Eyebrows</UiLabel> | Arched · Bushy · Furrowed · Raised · Straight · Thin |
| <UiLabel>Mouth</UiLabel> | Smile · Cat · Frown · Grin · Laugh · Neutral · Open · Smirk |
| <UiLabel>Hairstyle</UiLabel> | Crop · Bald · Bob · Braids · Bun · Buzz cut · Curly · Long · Ponytail · Side part · Spiky · Wavy |
| <UiLabel>Hair color</UiLabel> | Chestnut · Jet black · Espresso · Auburn · Copper · Honey blonde · Platinum · Silver · Lilac · Teal |
| <UiLabel>Outfit</UiLabel> | Hoodie · Cardigan · Lab coat · Robe · Scholar gown · Suit · Toga · Tunic |
| <UiLabel>Accessory</UiLabel> | None · Glasses · Headphones · Laurel · Monocle · Scarf |

Picking an occupation card on [Origin](/docs/guides/agents/forge/origin) also changes the outfit.

## Form parts

<UiLabel>What kind of being?</UiLabel> picks Creature, Plant, Object, Element, Machine, Place or Abstraction
(<UiLabel>Pick a kind; its forms appear under Form below.</UiLabel>). Then, as for portraits,
<UiLabel>Randomize</UiLabel>, part chips and <UiLabel>Re-roll …</UiLabel>:

<UiLabel>Form</UiLabel> · <UiLabel>Finish</UiLabel> · <UiLabel>Markings</UiLabel> · <UiLabel>Main color</UiLabel> ·
<UiLabel>Accent color</UiLabel> · <UiLabel>Eyes</UiLabel> · <UiLabel>Mouth</UiLabel> · <UiLabel>Accessory</UiLabel> ·
<UiLabel>Aura</UiLabel> · <UiLabel>Backdrop</UiLabel>

Changing the body on [Embodiment](/docs/guides/agents/forge/embodiment) swaps a generated portrait or
form for one that matches the new body.

## Emblem

<Screenshot id="forge-appearance-emblem" alt="An emblem preview, the hint that it is drawn from MBTI, Enneagram and temperament, and Redraw from personality" size="sm" />

The emblem is drawn from their MBTI type, Enneagram and temperament. When you change those later,
<UiLabel>Redraw from personality</UiLabel> becomes available and redraws it to match; it is disabled while
the emblem already matches.

## Photo

<Steps>
<Step>
### Import a photo
Choose <UiLabel>Photo</UiLabel>, or click <UiLabel>Import photo</UiLabel>. Pick a PNG, JPG, WebP, GIF or BMP
file in the <UiLabel>Choose a portrait photo</UiLabel> dialog. A copy is kept in your vault.
</Step>
<Step>
### Frame it
<UiLabel>Zoom</UiLabel> runs from 1.0× to 4.0×. The four arrow buttons move the picture inside the
circle; it always stays covered. <UiLabel>Reset framing</UiLabel> goes back to 1.0× and centred.
</Step>
</Steps>

If the file cannot be read, a notice says <UiLabel>Could not import the photo: …</UiLabel>

## Image ideas

<UiLabel>Image ideas</UiLabel> opens a sheet that builds a prompt for an image model when you have no
picture in mind, then draws it.

<Screenshot id="forge-image-ideas" alt="The Image ideas sheet: Style, Mood and Palette chips on the left; Surprise me, Write it for me, the prompt and a note that no image engine is set up on the right" />

| Part | What it does |
|---|---|
| <UiLabel>Style</UiLabel> | Illustration · Watercolour · Ink drawing · Isometric · Photographic · Pixel art · Paper collage · Clay figure |
| <UiLabel>Mood</UiLabel> | Calm · Hopeful · Playful · Mysterious · Dramatic · Melancholic |
| <UiLabel>Palette</UiLabel> | Match my theme · Warm · Cool · Monochrome · Pastel · Vivid · Earthy |
| <UiLabel>Framing</UiLabel> | Choices that suit an avatar, such as Head and shoulders or Emblem |
| <UiLabel>Keep out</UiLabel> | Text and letters · Watermarks · Distortions · Clutter · Blur |
| <UiLabel>Surprise me</UiLabel> | A random but coherent set of picks |
| <UiLabel>Write it for me</UiLabel> | Asks the language model for three ideas; <UiLabel>Use this</UiLabel> puts one in the prompt |
| <UiLabel>Prompt</UiLabel> | Rebuilt from your picks and the profile's body, mood and voice; edit it freely. <UiLabel>Kept out:</UiLabel> shows the negative prompt when the engine takes one. |
| <UiLabel>Generate</UiLabel> | Draws the prompt. <UiLabel>Stop</UiLabel> stops waiting. |
| <UiLabel>Set as avatar</UiLabel> | Under a picture: makes it the draft's photo avatar and closes the sheet |

The sheet draws with the agent's own image engine from the [Engine step](/docs/guides/agents/forge/engine),
or with the one in Settings › Images when the agent has none. Write it for me uses the model in
Settings › AI & Models and counts against the daily AI budget.

| Message | Fix |
|---|---|
| <UiLabel>No image engine is set up yet. Choose one in Settings › Images.</UiLabel> | Pick an image engine; <UiLabel>Open image settings</UiLabel> goes there |
| <UiLabel>The image engine needs a key. Add one in Settings › Images.</UiLabel> | Add the engine's key |
| <UiLabel>Writing ideas needs an AI model with a key. Add one in Settings › AI.</UiLabel> | Add a text-model key |
| <UiLabel>Today's AI budget is used up…</UiLabel> | Raise the budget, or wait for tomorrow |
| <UiLabel>The service could not be reached…</UiLabel> | Check the connection or the local server |

The same sheet opens from the composer, for a picture in a post, and from the palette command
<UiLabel>Image ideas for an avatar</UiLabel>.
