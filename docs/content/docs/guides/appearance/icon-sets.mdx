Beyond its built-in symbols, Simulacra can use thousands of icons as custom [symbols](/docs/guides/posts/symbols) on your posts. They come in 31 sets that are not bundled: you download the ones you want from **Settings › Symbols**.

<Screenshot id="appearance-icon-sets" alt="Settings › Symbols: the ICON SETS card with its note and a list of sets such as Outline icons · set 1 and Solid icons · set 2, each with its licence, icon count, size and a Download button" caption="Settings › Symbols, before any download." />

## Settings › Symbols

The card opens with <UiLabel>Each download fetches the icon package once (21.7 MB), checks it and keeps only the set you picked. See Licences for who made each set.</UiLabel>

Each row shows:

- **The set's label**: its style and number, such as <UiLabel>Line icons · set 9</UiLabel>. The styles are <UiLabel>Line icons</UiLabel>, <UiLabel>Outline icons</UiLabel>, <UiLabel>Solid icons</UiLabel>, <UiLabel>Rounded icons</UiLabel>, <UiLabel>Colour icons</UiLabel>, <UiLabel>Logos</UiLabel>, <UiLabel>Developer icons</UiLabel>, <UiLabel>Games & fantasy</UiLabel> and <UiLabel>Weather</UiLabel>.
- **Details**: its licence, icon count and size (`MIT · 287 icons · 129 KB`). For an installed set, the size is what it takes on disk.
- **The action**: <UiLabel>Download</UiLabel>, or <UiLabel>Remove</UiLabel> once installed.

## Download a set

<Steps>
<Step>
### Open Symbols

Press <Shortcut keys="Ctrl+," /> and click **Symbols** in the rail.
</Step>
<Step>
### Download

Click <UiLabel>Download</UiLabel> on a set. The button turns into a progress bar, a percentage and <UiLabel>Cancel</UiLabel>.
</Step>
<Step>
### Use it

When it finishes, a toast says <UiLabel>Icon set ready to use</UiLabel>. Its icons can now be found by name in the composer's symbol picker.
</Step>
</Steps>

<Screenshot id="appearance-icon-download" alt="One set row, Line icons · set 10, with its licence, icon count, size and Download button" caption="A set row before its download." size="sm" />

- **One at a time.** While a set downloads, the other Download buttons are disabled. <UiLabel>Cancel</UiLabel> stops it (<UiLabel>Download cancelled</UiLabel>).
- **Checked.** The package is checked against its published checksum. If it does not match, it is thrown away and nothing is installed: <UiLabel>The icon set could not be downloaded: the download did not match its checksum, so it was thrown away</UiLabel>.
- **Removing** a set deletes its files (<UiLabel>Icon set removed</UiLabel>).

## Settings › Licences

<Screenshot id="appearance-licences" alt="Settings › Licences with no set downloaded: the ICON SETS card saying no icon set is downloaded yet and that downloaded sets are listed here with their licences." caption="Settings › Licences before any download." size="md" />

**Licences** is the only place that names the projects behind the sets. It says <UiLabel>These icon sets were downloaded from the npm registry. Their makers and licences:</UiLabel> and lists each set you downloaded with its project and licence, the project's site, and the licence text stored with the set. Sets you have not downloaded are not listed. With none, the card says only <UiLabel>No icon set is downloaded yet. Sets you download in Symbols are listed here with their licences.</UiLabel>

## Tips and limits

- **Where they go.** Downloaded sets are stored in a `symbols` folder beside your database, each with its licence file. See [Data and files](/docs/reference/data-and-files).
- **Only when you ask.** The icon package is fetched from the npm registry only when you click <UiLabel>Download</UiLabel>, never in the background. See [Local-first](/docs/concepts/local-first).
- **Not in backups.** A backup or snapshot copies the database, not the `symbols` folder; download the sets again on a new computer, or copy the folder.
