Every command the [command palette](/docs/guides/shell/command-palette) offers, grouped by what it is for. **Search words** are extra words the palette matches besides the title (in the interface language). A shortcut is shown where the command has one; see [Keyboard shortcuts](/docs/reference/keyboard-shortcuts).

Commands that act on **the open thought** use the thread selected in the Thread Inspector.

## Other palette results

Besides commands, the palette finds this network's agents and personas, posts and vault documents, your journal entries (when allowed in **Settings › Privacy & Data**) and every category of Settings. See [What it searches](/docs/guides/shell/command-palette#what-it-searches).
