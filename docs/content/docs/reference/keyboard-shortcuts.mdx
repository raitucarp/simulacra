These are the bindings of the app's keymap, in the sections and order of the shortcut sheet (<Shortcut keys="Ctrl+/" />). The names are the sheet's own. On macOS, <Kbd>⌘</Kbd> replaces <Kbd>Ctrl</Kbd> and <Kbd>Alt</Kbd> is shown as <Kbd>⌥</Kbd>, except where a row says otherwise. How scopes work is explained in [Keyboard](/docs/guides/shell/keyboard).

**Where** names the scope: *Main window* works anywhere in the window, even while you type; the others work only in that part of the app.

## Keys not on the sheet

| Keys | Where | What they do |
|---|---|---|
| <Shortcut keys="Ctrl+V" /> | Main window, no text field focused | Paste anywhere: imports copied files, posts a copied image, captures copied text to your Inbox. |
| <Kbd>Enter</Kbd> / <Kbd>Esc</Kbd> | Quick capture | Save to your Inbox / close. |
| <Kbd>Esc</Kbd> | Main window | Closes the language or network menu, then the import sheet, then the Atomicity sheet; in the Knowledge Vault, leaves the reader or the add/edit form (like its Cancel) and closes the facet drawer. |
| <Kbd>↑</Kbd> <Kbd>↓</Kbd> | Thread Inspector, outline view | Previous / next row. |
| <Kbd>←</Kbd> <Kbd>→</Kbd> | Thread Inspector, outline view | Fold / unfold. |
| <Kbd>Enter</Kbd> | Thread Inspector, outline view | Open the row. |
| <Kbd>Home</Kbd> / <Kbd>End</Kbd> | Thread Inspector, outline view | First / last row. |
| <Kbd>Tab</Kbd>, then <Kbd>Enter</Kbd> or <Kbd>Space</Kbd> | Left sidebar | Move to a place, section or item; open it. |

## Commands without a shortcut

Every other command, such as <UiLabel>Switch network</UiLabel>, <UiLabel>Go to Tasks</UiLabel> or <UiLabel>Search posts</UiLabel>, runs from the [command palette](/docs/guides/shell/command-palette). They are all listed in the [commands reference](/docs/reference/commands).
