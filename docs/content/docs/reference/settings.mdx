## How settings are stored

- Each category is one JSON row (`preferences.general`, `preferences.writing`, …) in the vault's settings table, so an unreadable row resets only its category.
- Numbers are pulled into their range when loaded and on every edit; new cards per day never exceed the review limit, and chunk overlap never exceeds half a chunk.
- An option the app does not know (from a newer version or a hand-edited vault) reads as the default; telemetry always reads as off.
- The AI provider, its key and model keep their own rows; credentials are one JSON row; theme settings have their own rows.
